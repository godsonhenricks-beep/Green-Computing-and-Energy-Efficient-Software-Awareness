# Capstone 36 — Green Computing and Energy-Efficient Software Awareness

**Project question:** How can AI help teach students to write and run software in a more energy-efficient way?

**Target audience:** CSE students and campus IT staff.

## Repository structure
```
├── README.md
├── requirements.txt
├── code/
│   └── variants.py              # 2 code approaches (naive vs efficient)
├── scripts/
│   └── benchmark.py             # automation: logs runtime + estimated energy to CSV
├── results/
│   └── benchmark_results.csv    # generated by benchmark.py
├── docs/
│   ├── research_report.md       # research summary (fill with verified sources)
│   ├── green_software_checklist.md
│   ├── article.md               # 1,000-word article (outline + template)
│   ├── code_comparison.md
│   ├── before_after_analysis.md
│   ├── quiz_and_answer_key.md   # 10 questions + key
│   ├── prompt_library.md
│   ├── verification_report.md   # hallucination / outdated-info tests
│   └── ethics.md
├── infographic/
│   └── 10_green_habits.md       # content for the infographic (+ place image here)
└── slides/
    └── deck_outline.md          # 6-slide deck outline
```

## How to run
```bash
pip install -r requirements.txt
python scripts/benchmark.py
```
Results are written to `results/benchmark_results.csv`.
