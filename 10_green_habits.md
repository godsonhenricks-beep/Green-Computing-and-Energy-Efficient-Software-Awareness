# 10 Green Computing Habits (infographic content)

1. Pick efficient algorithms
2. Profile before you optimize
3. Cache repeated results
4. Stream, don't hoard data
5. Turn off idle machines
6. Right-size cloud resources
7. Remove unused code and dependencies
8. Compress and reduce data transfer
9. Use smaller AI models when possible
10. Measure, report honestly, avoid greenwashing
